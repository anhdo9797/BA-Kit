## Product Delivery Workflow (MANDATORY for any feature/PRD work)

`Phase 0 Discovery Interview → G0 → 1 PRD Draft → G1 → 2 Wireframe → G2 → 3 Review → G3 → 4 PRD Final + Design Final → G4 → 5 Development`

- `/ba-master` always interviews (Phase 0) before any PRD, wireframe or design.
- Every gate needs explicit user approval. PRD format is fixed: `.agent/templates/prd-template.md`.
- Wireframe: Markdown first → approve → HTML; Figma only on explicit confirmation.
- Artifacts: `outputs/<project>/<feature>/`; progress tracked in `_status.md`.
- Full protocol: `.agent/skills/ba-master/SKILL.md`.

## Development Principles
